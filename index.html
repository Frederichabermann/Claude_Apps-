Geräte-Sync über GitHub Gist
Optional: synchronisiere deine Daten geräteübergreifend über einen privaten GitHub Gist. Token und Gist-ID werden nur lokal in diesem Browser gespeichert (localStorage), niemals sonst wohin übertragen außer an die GitHub API.
Wichtig: Die Gist-API funktioniert nur mit einem klassischen Personal Access Token mit Scope gist (Einstellungen → Developer settings → Tokens (classic)) — ein "fine-grained" Token funktioniert dafür nicht.
Ablauf für 2 Geräte: Auf Gerät 1 Token eintragen, Gist-ID leer lassen, "↑ Hochladen" klicken — danach steht dort eine neue Gist-ID. Diese exakt gleiche ID auf Gerät 2 eintragen (Feld "Gist-ID"), dort denselben Token eintragen, dann "↓ Herunterladen". Ohne identische Gist-ID auf beiden Geräten entstehen sonst zwei getrennte, nicht verbundene Gists.
Beim Öffnen der App wird automatisch geprüft, ob im Gist ein neuerer Stand liegt — deine lokalen Änderungen werden dabei nie ungefragt überschrieben, solange du sie nicht schon hochgeladen hast.
